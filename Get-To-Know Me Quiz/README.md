# The Get-To-Know Me Quiz
## Available as a Source File or Application

### Download and open quiz.exe to play

This is a short quiz to get to know a little about me, with questions relating to my journey into technology, and some fun facts about me. 


This was my first project using C, and I had loads of fun. When I started this project, I originally wrote this out in the order it would output, and wrote out the question, answers, answer input, 'correct answer' message and 'incorrect answer' messages for each question in order, and it didn't sit right- why was I rewriting everything? The idea to change it to nested for loops was so much better, and a v2 was created.

I hope you enjoy the quiz, and have a wonderful day!
